Conceptos Básicos

  • Dominio:

    Se refiere al nombre de dominio de un sitio web, que es la dirección que se usa para acceder a él en la web.

  • Sub Dominio:

    Un subdominio no se define ni se utiliza directamente en el código. Los subdominios son una característica de la gestión de nombres de dominio y no son parte del lenguaje de marcado HTML.

  • URL:

    Es una dirección que identifica un recurso en la web, como una página web, una imagen o un archivo.

    • DNS:

    DNS es la sigla de "Domain Name System", que es el sistema que traduce los nombres de dominio (como www.ejemplo.com) a direcciones IP (como 192.168.1.1), que son necesarias para que los navegadores puedan acceder a un sitio web.

    Hosting:

    Es el servicio que permite que una página web, escrita en HTML y otros lenguajes de programación, esté disponible en Internet para que los usuarios puedan acceder a ella.

    FTP:

    Concepto que se utiliza para gestionar archivos en un servidor web.

    HTTP:

    Protocolo de Transferencia de Hipertexto (Hypertext Transfer Protocol).

    HTTPS:

    Es la versión segura de HTTP, el protocolo usado para la transmisión de datos en la web. La "S" significa "seguro" y se utiliza para indicar que la comunicación entre el navegador y el servidor web está cifrada, protegiendo la información transmitida.

    W3C:

    Significa que el World Wide Web Consortium (W3C), una organización internacional, es la encargada de desarrollar y establecer los estándares para el lenguaje HTML.

    UFT-8:

    Formato de codificación de caracteres Unicode que ha revolucionado el mundo digital. Es el responsable de que tu navegador o tu cliente de correo te muestre el contenido del texto correctamente decodificado, sin errores ni caracteres extraños.

    HTML5 y su Esctructura:

    Es la última versión del lenguaje de marcado de hipertexto, usado para estructurar el contenido de las páginas web. Su estructura incluye etiquetas que definen la organización de la página, como encabezados, párrafos, listas, tablas, entre otros. HTML5 introduce elementos semánticos, mejora el soporte multimedia y ofrece mejoras en la interoperabilidad y el rendimiento, especialmente en dispositivos móviles.
